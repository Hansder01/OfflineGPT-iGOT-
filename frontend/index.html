Security Policy & Rate Limit Rules

Sliding Window Protection

To prevent system abuse and manage API token budgets, Offline GPT enforces a sliding window rate limit per session/IP address.

Automatic Cooldown Reset

Once you reach the 10 prompt limit, prompt execution will pause. The cooldown timer counts down in real time and automatically unlocks your quota once expired.

Database Session Tracking

Active user sessions and usage logs are stored securely in the local SQLite database (`app.db`). Logged in users get dedicated session tracking.

About Offline GPT

Offline GPT is a full-stack Agentic AI platform built with Python, FastAPI, SQLite, and modern web UI technologies. Designed to operate 100% offline with zero external telemetry, or seamlessly connect to free tier cloud models.

Free API Keys Supported

Configured for free tier Google Gemini API (`GEMINI_API_KEY`) and Groq (`GROQ_API_KEY`) in `.env` file.

Interactive Hacker CLI

Free API Keys & .env Setup

You can use Offline GPT in **100% Offline Mode**, or paste free API keys in your local `.env` file for enhanced neural capabilities:

# Offline GPT .env Configuration

# Free Google Gemini API Key (Get at: https://aistudio.google.com/)
GEMINI_API_KEY=AIzaSy...

# Free Groq API Key (Get at: https://console.groq.com/)
GROQ_API_KEY=gsk_...

# Rate Limiting Parameters
RATE_LIMIT_PROMPTS=10
RATE_LIMIT_WINDOW_SECONDS=300
  1. Open the .env file in your project root folder.
  2. Paste your free Gemini or Groq API key.
  3. Save the file — system auto-detects API key changes!
